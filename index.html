Neuron Finalizado

Jogo acessível por comando de voz para inclusão de pessoas com limitações motoras

O Neuron é um jogo de enigmas pensado para incluir jogadores com limitações motoras graves, como tetraplegia, permitindo que participem das dinâmicas sem barreiras. O usuário responde aos desafios por comando de voz, processado em Python e enviado por porta serial ao Arduino. Num tabuleiro físico, LEDs representam as "casas" e marcam o avanço dos jogadores a cada enigma resolvido — unindo hardware, software e acessibilidade num só projeto.

CITi Legacy Protótipo

Visualizador interno dos projetos do CITi, com acompanhamento semanal gerado a partir dos commits

O CITi Legacy é um protótipo criado para o desafio "Inovação no PS" do CITi. Ele reúne todos os projetos da empresa, em andamento e concluídos, em um só lugar. Tudo é calculado a partir dos commits: o status de cada etapa (inclusive projetos parados há mais de 14 dias) e o Índice de Conhecimento de cada membro. Resumos semanais com IA (Gemini) são gerados automaticamente, e há exportação em PDF e boletim por e-mail. Desenvolvido com apoio de IA.

TypeScript Next.js Tailwind CSS PostgreSQL Vercel Gemini API

Calculadora SSA Finalizado

Calculadora de notas do vestibular SSA da UPE com comparação às notas de corte

A Calculadora SSA calcula a nota dos estudantes no vestibular estadual de Pernambuco (SSA) seguindo a fórmula de cálculo disponível no edital. Há também um espaço para o estudante comparar sua nota com as notas de corte do ano anterior. Desenvolvida com apoio de IA.
